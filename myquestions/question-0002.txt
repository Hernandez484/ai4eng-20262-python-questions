Nombre de la función: predecir_eficiencia_reducida

El Problema:
Cuando se tienen demasiadas variables correlacionadas, es mejor reducir la dimensionalidad antes de aplicar regresión para evitar el sobreajuste.

Misión:
Escribe una función llamada predecir_eficiencia_reducida(X, y, n_componentes) que:
1. Use sklearn.decomposition.PCA para reducir la matriz X al número de componentes especificado.
2. Use sklearn.linear_model.Lasso con un alpha de 0.5 para entrenar un modelo de regresión sobre los componentes obtenidos.
3. Calcule la Varianza Explicada Acumulada de los componentes seleccionados usando numpy.
4. Devuelva un diccionario con las claves: 'modelo', 'varianza_total' (float) y 'coeficientes' (array de coeficientes del modelo).

Librerías requeridas: numpy, sklearn.
