Nombre de la función: clasificar_sensores_con_ventanas

El Problema:
En entornos industriales, los datos crudos suelen ser ruidosos. Debes crear una función que prepare una serie temporal y la clasifique.

Misión:
Escribe una función llamada clasificar_sensores_con_ventanas(df, target_col, ventana=3) que:
1. Use pandas para calcular la desviación estándar móvil (rolling standard deviation) de las columnas numéricas usando el tamaño de 'ventana'.
2. Use numpy para sustituir cualquier valor infinito (inf) por NaN y luego elimine todas las filas con valores faltantes.
3. Use sklearn para entrenar un modelo LinearSVC.
4. Devuelva una tupla con (modelo_entrenado, accuracy_score).

Librerías requeridas: pandas, numpy, sklearn.
